# Data Science Digital Library

A static, browser-based student learning portal for data science coursework.

## Open the library

Open `index.html` in a browser. No build step or package installation is required.

## Features

- Home dashboard and student profile page
- Five data science course modules
- Module 1 and Module 2 presentation notebooks with animated page turns
- Original PowerPoint downloads
- Lab assignment links, study resources, tools, exam revision prompts, and viva practice

The profile displays generic placeholder details. Add student-specific information only in a private local copy; do not publish personal records or student photos.

## Public website

This repository includes a GitHub Actions workflow to deploy the static site to GitHub Pages. After pushing the workflow to `main` and enabling Pages with **Settings → Pages → Build and deployment → GitHub Actions**, the public site will be available at `https://bm150633-coder.github.io/Digital-Library/`.

Student profile details are saved in the visitor's browser and are not included in the repository. The default profile is generic.
